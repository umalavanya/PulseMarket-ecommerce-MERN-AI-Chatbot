🧠 DATA STRUCTURES & ALGORITHMS (RESUME GOLD)
═══════════════════════════════════════════════════════
Implement in `server/algorithms/` and `client/src/utils/`:

1.  Trie             → autocomplete search suggestions (O(L) per lookup)
2.  Merge Sort       → price sorting (stable, O(n log n))
3.  Quick Sort       → rating sorting (in-place, O(n log n) avg)
4.  Binary Search    → price range filter on sorted array (O(log n))
5.  Hash Map         → O(1) category lookup
6.  Set              → wishlist deduplication
7.  LRU Cache        → recent product queries (capacity 50)
8.  Min-Heap (PQ)    → "cheapest N items" + express-delivery order priority
9.  Sliding Window   → trending products (last 7 days)
10. BFS on Graph     → "customers also bought" recommendations
11. Cosine Similarity→ content-based recommendations
12. Debouncing       → useDebounce hook for search input

Each file MUST include JSDoc with Time/Space complexity comments.

🗄️ MONGOOSE MODELS
═══════════════════════════════════════════════════════
User:    { name, email (unique+indexed), password (hashed), role (enum), avatar,
           addresses[], wishlist[], createdAt }
         - Pre-save hook: bcryptjs.hash(password, 12)
         - Method: comparePassword(candidate)

Product: { name (text index), slug, description, price, mrp, discount, category (indexed),
           brand, images[], stock, rating, numReviews, sellerId (ref), tags[] }
         - Compound index: { category: 1, price: 1 }
         - Text index: { name: 'text', description: 'text' }

Order:   { userId (ref+indexed), items[{ productId, qty, price }], totalAmount,
           shippingAddress, paymentMethod, status (enum), timeline[] }

Cart:    { userId (unique), items[], updatedAt }
Review:  { userId, productId, rating, comment, createdAt }
         - Compound unique index on (userId, productId)
